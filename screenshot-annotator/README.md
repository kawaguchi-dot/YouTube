# Screenshot Annotator

スクリーンショットや動画に矢印・図形・テキスト・モザイクなどの注釈を追加できる
Chrome 拡張機能（画像編集ツール）です。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」から、この
   `screenshot-annotator` フォルダを選択する
4. ツールバーの拡張機能アイコンをクリックすると編集画面が開きます

## 描画ツール

| ツール | ショートカット | 説明 |
| --- | --- | --- |
| 選択 | `V` | オブジェクトを選択・移動・編集 |
| テキスト | `T` | テキストを追加 |
| ステップマーカー | – | クリックで連番（①②③…）を追加 |
| 四角形 | `R` | 四角形を描画（角丸／直角を選択可） |
| 円・楕円 | `C` | 円・楕円を描画 |
| 矢印 | `A` | 矢印を描画 |
| **マーカー** | **`P`** | **フリーハンドで線を描画（太さ・色を変更可）** |
| モザイク | `M` | モザイク効果を適用 |

## v2.2.0 で追加・修正

- **マーカー（フリーハンド）ツール `P`**: 好きな軌跡で線を描けます。太さ・色は
  ツールバーの設定に連動し、描いた線を選択して後から色を変えることもできます。
  - **「直線」トグル**（マーカー選択時に表示）を ON にすると、マーカーが
    **水平・垂直の直線**になります。ドラッグの向きで自動的に水平か垂直を判定します。
- **テキストボックスの複製**: オブジェクトを右クリック →「複製」、または `Ctrl+D`。
  テキストボックスもそのままコピーできます。
- **テキスト書き換えの不具合修正**: これまで日本語テキストをダブルクリックすると
  全文が選択され、入力すると全消えしていました。ダブルクリックした位置に
  カーソルが入り、文字を挿入・修正できるように修正しました。
- **四角形の角丸／直角の切り替え**: プロパティバーの「角丸」トグルで、四角形の角を
  丸角と直角で選べます。選択中の四角形にも反映されます。
- **Nextstep ブランド対応**: トップバナーをイエロー（#FFF315）系グラデーションに
  変更し、左端に Nextstep ロゴを表示するようにしました。

### アイコン・ファビコン・ロゴ

- 拡張機能アイコン（`icons/icon16.png` / `icon48.png` / `icon128.png`）と
  編集画面タブのファビコン（`icons/favicon.png`）を Nextstep の「n」マークに設定しています。
- ツールバー左端には「n」マーク＋「Nextstep」を表示します。
- これらの画像は Nextstep ロゴを再現したものです。差し替えたい場合は
  `icons/` 内の該当 PNG を同名で置き換えてください（マーク画像が読めない場合は
  ツールバーはテキストのみ表示にフォールバックします）。

## 色を選択できる図形（v2.1.0 で追加）

- **円・楕円ツール（`C`）** を追加しました。ドラッグで自由なサイズの円・楕円を描けます。
- プロパティバーに **「塗りつぶし」トグル** を追加しました。
  - **OFF**（既定）: これまで通り、選択した色の「枠線」だけの図形を描きます。
  - **ON**: 四角形・円を、選択した色（カスタムカラー／グラデーション対応）で
    塗りつぶして描きます。
- 塗りつぶしトグルは **選択中の図形にも即時反映** されます。
  既存の図形を選択してトグルを切り替えると、枠線⇔塗りつぶしを後から変更できます。
- 塗りつぶした図形は、カラーパレット／カスタムカラーで **塗りの色を変更** できます。

色・太さ・塗りつぶしの設定は保存され、次回起動時に復元されます。

## その他の主な機能

- オブジェクトの複製（右クリック →「複製」／ `Ctrl+D`）
- レイヤー操作（最前面／前面／背面／最背面）
- Undo / Redo（`Ctrl+Z` / `Ctrl+Y`）
- PNG 保存・クリップボードへコピー（いずれも 2 倍解像度）
- 範囲指定トリミング
- 画像・動画の読み込み（貼り付け・ドラッグ＆ドロップ対応）、動画コントロール
