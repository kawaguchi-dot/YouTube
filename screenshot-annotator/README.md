# Screenshot Annotator

スクリーンショットや動画に矢印・図形・テキスト・モザイクなどの注釈を追加できる
Chrome 拡張機能（画像編集ツール）です。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」から、この
   `screenshot-annotator` フォルダを選択する
4. ツールバーの拡張機能アイコンをクリックすると編集画面が開きます

## 描画ツール

| ツール | ショートカット | 説明 |
| --- | --- | --- |
| 選択 | `V` | オブジェクトを選択・移動・編集 |
| テキスト | `T` | テキストを追加 |
| ステップマーカー | – | クリックで連番（①②③…）を追加 |
| 四角形 | `R` | 四角形を描画 |
| **円・楕円** | **`C`** | **円・楕円を描画（今回追加）** |
| 矢印 | `A` | 矢印を描画 |
| モザイク | `M` | モザイク効果を適用 |

## 色を選択できる図形（v2.1.0 で追加）

- **円・楕円ツール（`C`）** を追加しました。ドラッグで自由なサイズの円・楕円を描けます。
- プロパティバーに **「塗りつぶし」トグル** を追加しました。
  - **OFF**（既定）: これまで通り、選択した色の「枠線」だけの図形を描きます。
  - **ON**: 四角形・円を、選択した色（カスタムカラー／グラデーション対応）で
    塗りつぶして描きます。
- 塗りつぶしトグルは **選択中の図形にも即時反映** されます。
  既存の図形を選択してトグルを切り替えると、枠線⇔塗りつぶしを後から変更できます。
- 塗りつぶした図形は、カラーパレット／カスタムカラーで **塗りの色を変更** できます。

色・太さ・塗りつぶしの設定は保存され、次回起動時に復元されます。

## その他の主な機能

- レイヤー操作（最前面／前面／背面／最背面）
- Undo / Redo（`Ctrl+Z` / `Ctrl+Y`）
- PNG 保存・クリップボードへコピー（いずれも 2 倍解像度）
- 範囲指定トリミング
- 画像・動画の読み込み（貼り付け・ドラッグ＆ドロップ対応）、動画コントロール
